# Task: Mobile Registration 6-Digit OTP Verification Screen and Onboarding Flow

## Outcome

Enable newly registered students on `sentinel-mobile` to seamlessly verify their email with a 6-digit OTP code on a dedicated native screen matching Sentinel's modern theme, unblock mobile registration from Cloudflare Turnstile captcha rejection, and strictly redirect students to `/(onboarding)` upon verification.

## Pre-planning record

### Actors and goals

- **Registering Student (`sentinel-mobile`):**
  - Fill out registration form and submit credentials without `captcha protection: request disallowed (no captcha_token found)`.
  - Automatically land on `/(auth)/confirm-code` with email pre-populated and receive 6-digit confirmation code.
  - Enter or paste 6-digit code into a modern 6-cell PIN input with automatic submission on the 6th digit.
  - Request a code resend with a 60-second cooldown timer if the email was missed.
  - Immediately enter `/(onboarding)` upon successful verification without being routed to login.
  - Return to `/(auth)/register` via "Change email address" if the email was mistyped.

### Domain language

- **Email Confirmation OTP:** 6-digit numeric token generated by Supabase GoTrue and sent via email template (`confirmation.html`).
- **Service Role Registration Bypass:** In `sentinel-api`, routing mobile registration requests lacking Turnstile tokens (`x-sentinel-client: mobile`) to `supabaseAdmin.auth.signUp(...)` while preserving IP rate limiting (30 attempts/5 min) and audit logging.
- **6-Cell OTP Input:** Visual PIN component presenting 6 discrete rounded digit cells with active border `#323d8f`, powered by an underlying accessible `TextInput`.
- **Post-OTP Redirection:** Strict navigation to `/(onboarding)` via `router.replace('/(onboarding)')` to clear the auth navigation stack.

- Update `sentinel-api` `AuthService.register` and `register.controller.ts` to support `x-sentinel-client: mobile`.
- Create `components/auth/auth-otp-input.tsx` for 6-digit cell input.
- Create `app/(auth)/style/confirm-code.ts` and `app/(auth)/hooks/use-confirm-code-form.ts`.
- Create `app/(auth)/confirm-code.tsx` screen.
- Update `app/(auth)/hooks/use-register-form.ts` to redirect to `confirm-code`.
- Add comprehensive Vitest test suites for API service, OTP input component, and confirm-code hook.

## Non-goals

- In-app password reset OTP code entry (password reset uses web update link).
- Phone / SMS verification.
- Modifications to registration form fields (first name, last name, email, password remain standard).
