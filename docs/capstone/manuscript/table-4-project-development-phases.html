Project Development Methodology

To manage the complexity of integrating real-time telemetry, AI-driven proctoring, and secure assessment delivery, this project utilized an Iterative software development life cycle (SDLC) model. This approach allowed the development team to build the system incrementally, starting with a functional baseline and systematically refining features through successive iterations. Table 4 outlines the detailed activities and required deliverables across the successive development phases of the Sentinel platform.

Table 4

1. Requirements & Analysis

Interview academic stakeholders (deans, department chairs, instructors, and students) to identify exam pain points and institutional requirements.

Analyze legacy and online examination workflows to identify cheating vulnerabilities, scalability bottlenecks, and proctoring limitations.

Define functional requirements (exam authoring, kiosk runtime, AI proctoring) and non-functional requirements (security, concurrency, sub-second telemetry latency).

Perform feasibility study and privacy risk assessment regarding on-device camera/microphone processing and cloud data residency.

4. Testing & Integration

Execute automated unit tests on backend API endpoints, Zod validation schemas, and database transactions.

Benchmark Edge AI vision and audio inference performance (FPS, CPU/memory consumption, latency).

Administer formal User Acceptance Testing (UAT) with faculty and student participants using standardized evaluation instruments (ISO 25010 / SUS).
